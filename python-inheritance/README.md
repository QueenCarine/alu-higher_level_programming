# Python - Inheritance

This directory contains Python tasks on inheritance and object introspection.

## Files

| File | Description |
| --- | --- |
| `0-lookup.py` | Function that returns the list of available attributes and methods of an object |
| `1-my_list.py` | Class `MyList` that inherits from list and prints it sorted |
| `2-is_same_class.py` | Function that checks if an object is exactly an instance of a class |
| `tests/1-my_list.txt` | Doctests for `MyList` |
| `3-is_kind_of_class.py` | Function that checks if an object is an instance of, or inherits from, a class |
| `4-inherits_from.py` | Function that checks if an object is an instance of a subclass of a class |
| `5-base_geometry.py` | Empty class `BaseGeometry` |
