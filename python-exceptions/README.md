# Python - Exceptions

This directory contains Python scripts covering exception handling with try/except.

## Files

- `0-safe_print_list.py`: function that prints x elements of a list and returns the number of elements printed.
- `1-safe_print_integer.py`: function that prints an integer with "{:d}".format().
- `2-safe_print_list_integers.py`: function that prints the first x elements of a list, only integers.
- `3-safe_print_division.py`: function that divides 2 integers and prints the result in a finally block.
